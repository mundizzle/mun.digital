If you build a product website in 2026, you have two audiences. One of them types with their thumbs. The other one types with a Python loop.

I rebuilt mun.digital specifically to be readable by both. The same sanitized resume data powers visible HTML, generated PDF, Markdown, npm CLI, and a public MCP endpoint.

### What changes

When you accept that an agent is a user, three things stop making sense:

- Marketing copy. An agent will not be persuaded by world-class solutions. It will be persuaded by structured facts.
- Decorative imagery. An OG image is for a Slack unfurl. The real OG is the markdown.
- Trapped data. Your contact form, scroll-jacked timeline, and interactive resume are invisible to the loop.

### What survives

Typography. Structure. Hierarchy. Tone. If a page reads like a manual, an agent can summarize it. If it reads like a marketing landing, it cannot.

> Build the website so that an LLM running curl with text/markdown gets the same value as a human with a retina display.

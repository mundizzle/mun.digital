---
title: "A 20-component design system in Rails view helpers"
date: "2026-02-18"
---

You can ship a design system in Rails. You can even like it. The trick is to stop reaching for React by default and start trusting the rendering model your product already uses.

The best component API is the one your team will actually maintain. In a Rails product, that often means boring helper methods, clear slots, predictable class composition, and tests that stay close to the rendered HTML.
